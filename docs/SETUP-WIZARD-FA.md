## 🚀 جادوگر نصب — فقط ۳ قدم!

### قدم ۰: چی لازم داری؟ (۳۰ ثانیه)

یک کامپیوتر با اینترنت — همین! Docker جعبه جادویی — جادوگر چک می‌کنه.

### قدم ۱: دانلود (۳۰ ثانیه)

```bash
git clone https://github.com/ansariaiadmin/legal-platform.git
cd legal-platform
```
یا zip از Releases → Extract

### قدم ۲: جادوگر نصب — فقط Enter! (۱ دقیقه)

**ویندوز:** `install.bat` دوبار کلیک

**مک/لینوکس:**
```bash
chmod +x install.sh
./install.sh
```

**چی می‌بینی؟**
```
[1/6] بررسی سیستم... ✓
[2/6] Docker... ✓ Docker 24.0.5 + Compose V2
[3/6] Git... ✓
[4/6] وابستگی‌ها... ✓ Docker کافیه!
[5/6] تنظیمات — رمزهای بانکی 32 کاراکتری... ✓ .env ساخته شد
[6/6] ساخت و اجرا — docker compose up --build -d
....................
✓ آماده! — Frontend http://localhost:3000 + API http://localhost:8000

آدرس: http://localhost:3000
```

### قدم ۳: استفاده (۱۰ ثانیه)

مرورگر → `http://localhost:3000`

**چی می‌بینی؟**
- داشبورد فارسی — پرونده‌ها، موکل‌ها، مالی، AI
- AI Workspace — سوال بپرس: "قرارداد اجاره چطور فسخ می‌شه؟" — ۶ وکیل AI جواب می‌ده!
- اسناد — PDF آپلود → OCR → RAG
- E-Signature — قرارداد رو امضا کن با موس — ذخیره امن
- PWA — رو موبایل نصب کن — تو دادگاه استفاده کن

**.env خراب:** `rm .env` + `cp .env.example .env` + `./install.sh`

**سرویس بالا نمی‌آد:** `./logs.sh` — لاگ بخون
